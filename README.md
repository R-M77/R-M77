## Engineering principles

- Make claims traceable to tests, measurements, or primary sources.
- Separate synthetic estimates from real hardware measurements.
- Design for reproducibility before adding complexity.
- Keep safety, data boundaries, and failure modes explicit.
- Prefer a small working vertical slice over a large unfinished framework.
